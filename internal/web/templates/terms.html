Responsible use

Operators should define acceptable use for admins, API clients, CI jobs, and automation. Use Packmon only for authorized dependency-security, inventory, feed-management, and operational audit workflows.

Credentials and integrations

API key responsibilities include storing keys in approved secret stores, rotating or revoking keys when exposure is suspected, and using named keys for each client class or runner group. Optional third-party feed providers and webhook recipients can receive package coordinates or scan-result data when operators configure those integrations.

Changes and suspension

Operators should publish amendment, suspension, termination, and incident response rules for their deployment, including how users are notified when API keys, feed imports, admin access, or scanning workflows are limited.
